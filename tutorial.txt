ls - list  all files/directory inside directory
cd - change directory
cd ..  - move inside folder
clear - clear terminal
exit - exit terminal

git and github 

Github - platform for keep their repository/project

git - Version Control System (it controls our project different versions/state)
 


git init - Initialize "git" inside repository

git add .  - stage all files 

git commit -m "make github and git tutorial"

git log - commit history 

git status - current status of your project

git remote  add origin  "url " - for adding remote to local repository

git remote -v  - for seeing remote url

git remote remove origin - remove current remote url 


git pull origin main - pulling changes from origin/remote
